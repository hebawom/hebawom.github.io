# Retirement website

A self-contained static website: app introduction, privacy policy, terms and support. It uses plain HTML/CSS, system fonts and local images. No build step, analytics, cookies, third-party embeds or form service is added.

## Preview

Open `index.html` in a browser. Navigation also works when hosted under a GitHub repository path.

## Publish with GitHub Pages

1. Create a separate public GitHub repository, for example `retirement-app`. Publishing only this folder avoids making the app's source code public. GitHub Free supports Pages for public repositories.
2. Upload the **contents** of this folder, including `index.html`, `styles.css`, `assets/`, the policy/support pages and `.nojekyll`, to the root of the repository's `main` branch.
3. In the repository, open **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, then **main / (root)**, and save.
4. GitHub displays the published address, normally `https://USERNAME.github.io/REPOSITORY/`. Enable HTTPS if it is offered. A custom domain can be added later; none is necessary to begin.
5. Use the main address as the marketing URL, `privacy.html` as the privacy-policy URL and `support.html` as the support URL in App Store Connect. Add the final privacy URL to the app once the real address is known.

No GitHub repository or public deployment has been created by preparing these files.

## Updating screenshots

The asset manifest is `assets/screenshots/manifest.json`. It records source filenames, output sizes and compression totals without capture metadata. The surrounding phone is a custom front illustration, not an Apple-supplied product image; its current-device reference is [iPhone 17](https://www.apple.com/uk/iphone-17/specs/).

`../Tools/prepare_website_screenshots.py` reproduces the images from the source PNG folder using Pillow. Framed variants are in `assets/screenshots/framed/`; plain compressed screens are in `assets/screenshots/screens/`. Small variants load on lower-density screens; larger variants stay sharp on Retina displays. Gallery images load only as needed.
